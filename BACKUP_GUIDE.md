# Meemz Cameo — Backups

Download a JSON backup from the dashboard:

1. Open `/admin.html` and log in as the main admin.
2. Go to **Settings** (الإعدادات).
3. Click **Download backup** (تنزيل نسخة احتياطية).

The backup includes products, orders, settings and safe user fields (no passwords).
For database-level backups, enable scheduled backups in the Supabase dashboard.
